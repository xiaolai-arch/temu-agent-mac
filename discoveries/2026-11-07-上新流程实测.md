# TEMU 上新流程实测（2026-11-07，store-d / fenzhenYY）

首个跑通的商品：个性化小傻鹅洗礼/一岁生日餐巾纸（派对餐巾类目）。
草稿：`https://agentseller.temu.com/goods/edit?productDraftId=46699861611`

## 流程与页面事实

1. 新建商品 → 类目搜索框输入关键词（如「派对餐巾」）→ 点搜索结果的**全路径 div**
   （`text=` 匹配不到）→「下一步」→ 进入 `goods/edit?productDraftId=...`。
2. 轮播图：素材中心弹窗 → 本地上传/选素材。**选择顺序 = 轮播顺序**；已选满 5 张时
   再点不会增加，先删空再按序重选（容量 10 张）。删图标 class
   `preview-image_deleteIcon__81nJ2`。
3. 规格：平台父规格没有「尺寸」，用 **尺码**；值直接写 `23cm×23cm`。
   - **规格值必须真实键盘输入 + 失焦/Enter 提交**，才会生成 SKU 列；用 JS 直接 set
     value 不触发 React 状态（表现：输入框有值但 SKU 表不出现该列、下方红字「请输入」）。
   - 数量值必须带单位：`25pcs/set` 通过；`25 sheets/set` 被判定为空（红字请输入）。
   - SKU 表生成后，申报价格输入才可用。
4. 成分陷阱：纸类类目没有「纸」选项；「其他纤维」单独占比 100% 违规
   （规则：单独一种 <5%，多种合计 <15%）。只有一行时删除按钮 disabled——
   先点「添加」出第二行，删除「其他纤维」行后留一个空行，报错消失。
5. 包装信息：一个 `input[type=file][multiple]`，`setInputFiles` 一次传 3 张；
   外包装类型/形状 radio 默认已选「硬包装」「长方体」。
6. 敏感属性：默认「是」，弹层选「否」后，体积/重量 5 个输入才解锁
   （最长边/次长边/最短边 cm + 重量 g + 净重 g）。
7. 保存成功信号：弹窗「保存成功 提交商品信息且创建成功后方可生效」。
   「创建」= 提交上架，属写操作，需用户明确确认后再点。
   - 点「创建」先弹「平台报关需根据商品所属类型确定关税」：单选 餐纸 / 餐巾 / 纸巾 /
     一次性餐具 / 都不是，自定义 → 确认。本次选「餐巾」（派对餐巾最准确）。
   - 成功弹窗「定制商品创建成功」→「立即维护」跳到
     `goods/list?productId=...&showCustomizedDrawer=1`，打开「修改定制信息」抽屉。
   - 抽屉步骤：1 配置定制信息 → 2 填写库存。列表行状态「无配置」，操作列有「配置」。
   - 抽屉上会再压一个待办弹窗（“您有以下待办任务需要尽快处理”），关闭 X 是
     `MDL_iconWrapper` 类，悬在右上角外侧。
   - 配置定制信息需上传**背景图**（宽高 800~2000px、<3M；不能带示例文字，否则示例字样
     会被印进成品）并画**定制区域**（类型 图片/文字、起点坐标 X/Y、尺寸 宽/高、
     最小像素要求、消费者购买时是否必须上传）。
8. **定制商品**：选中后新增必填「工艺类型」（单一工艺/组合工艺）；本次选单一工艺后
   出现两个必填下拉：大类选「画布/纸张定制工艺」，工艺选「UV」（另有丝网印刷-文字/
   图片、烫金-文字/图片、压印、手绘）。平台提示定制开启后还需另行配置「定制模版内容」
   （不在本表单，创建后到定制商品页处理）。
9. **多数量规格**：数量父规格可点「+ 继续添加子规格」加多行。参考现有 SKC 83950723833
   的档位，本次填 15 / 25 / 52 / 75 pcs/set。SKU 表自动生成 4 行，尺码 23cm×23cm 为
   rowspan 合并。申报价按参考建议价 ×1.73：15→39.9、25→45、52→60.9、75→72.9 CNY。
10. 体积重量表**按 SKU 数展开**：每个数量行都要单独选「敏感属性=否」并填
   最长边/次长边/最短边/重量/净重（选「否」后输入才解锁）。
11. 组合工艺：二级工艺是**多选且至少两项**，同一项不能选两次；本次按实际选
   「丝网印刷-文字 + 丝网印刷-图片」。切换单选/组合会清空已选工艺。
12. 商品产地的「省份」下拉有时会掉（只剩国家），且报「不能为空」——重新选
   中国大陆后出现 `input[placeholder="请选择省份"]`，选河南省。

## 待决策

- **定制信息未配置**（用户要求先不做）：上架前需补「填写定制信息」的底图 + 定制区域，
  再走「保存并下一步」填库存，否则可能影响后续流程。
- 3 张包装图是通用无标签纸箱，平台要求外包装图含商品分类信息（名称/说明），
  仓库可能拒收。
- 重量/体积为估算值，需按实物复核。
