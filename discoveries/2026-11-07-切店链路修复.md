# 切店链路修复（2026-11-07）— 平台 11-01 改版

## 症状
- 11-01 起 main/store-c 切店全部 verifyfail：卡在 Seller Central「商家中心」门，
  SSO 弹窗白屏，主窗永不跳转。10-30 仍成功（110s），11-01 起 4 次连续失败。

## 根因（三个叠加）
1. **登录页新增协议勾选框**（默认不勾）→ 点「登录」无反应 → failpage。
   修复：`doLogin` 前 `tickLoginAgreement`（点 `label[data-testid=beast-core-checkbox]`
   里的 `.CBX_square`）。
2. **佳同「弹框已禁用」药丸贴视口右缘**（core 1197→1281，视口宽 1279），旧坐标
   点击（文字右侧 +14px）落空；且插件注入有延迟（新开页 5s+）——点早了等于没点。
   修复：`restoreDialogSwitch` 先等药丸出现，再 DOM click `.yd-switch__core`。
3. **授权卡选择器误伤**：页面上第一个 `input[type=checkbox]` 是插件 yd-switch
   （checked=true = 禁用态），旧代码按序取会勾插件开关、并误判「已勾协议」。
   修复：只认 `label[data-testid=beast-core-checkbox]`；确认按钮点 `button` 本体
   （叶子 span 在卡片隐藏时 rect=0×0）。

## 白屏机制
`seller.kuajingmaihuo.com/settle/seller-login` 的微前端（#root）在「弹框已禁用」
状态下**不挂载** → 弹窗永远空白、无 console 报错；恢复开关 + reload 后立即渲染授权卡：
「即将前往 Seller Central (全球) 的「hpoiZee」店铺…确认授权并前往」。

## 验证（2026-11-07）
- 受控实验：门 → 弹窗 → 勾协议 → 确认 → **主窗 2.5s 跳到 customize-goods**。
- `run switch-store main` → 已在目标店（hpoiZee，双按钮✅）exit 0。
- `run sync-check main` → 体检通过（登录态/账号/双按钮全绿）。

## 现行页面事实（与旧笔记的差异）
- seller.kuajingmaihuo.com 侧边栏**已无「定制商品内容」子菜单**，旧侧边栏联动
  路径失效；现行授权路径 = Agent Center 门（auth/authentication）→ 商家中心卡片
  → SSO 弹窗（settle/seller-login）。
- 每个标签页独立注入「弹框已禁用/已恢复」药丸；状态在 reload 后保持。
- 授权弹窗的 state 令牌有时效：门页打开过久再授权，主窗可能不跳——整条链路应在
  一次运行内完成（脚本已如此）。
