# 2026-11-08 TEMU 采集实测（商品库数据源）

目标：替代妙手采集箱，采集竞品「类目 / 标题 / 主图」。本期聚焦**定制餐巾**。
结论：两条可用链路已跑通，脚本在 `modules/collect/`：

| 链路 | 脚本 | 产物 | 状态 |
|---|---|---|---|
| 卖家中心「机会商品」 | `temu-collect.mjs` | `data/temu-opportunity-*.jsonl` + `data/images/` | ✅ 全量翻页可用 |
| 消费者站搜索 | `temu-search.mjs` | `data/temu-consumer-*.jsonl` + `data/images-consumer/` | ⚠️ 采 40 条后触发登录墙 |

## 消费者站搜索（www.temu.com/search_result.html）

- 匿名可访问，中文界面/英镑价格（自动落到 UK 站）；搜索 `custom napkin` 能命中大量定制餐巾。
- 卡片 DOM：
  - 卡片容器 `.earth-wxt-collect-warp`（妙手插件注入的类名，不影响数据）
  - 标题：`[data-tooltip^="goodName-"]` 的 `data-tooltip-title`（本地化中文标题）
  - 主图：`img.goods-img-external`，src 形如
    `https://img.kwcdn.com/product/...jpeg?imageView2/2/w/500/q/70/format/avif`
  - 商品 ID：卡片链接 `a[href*="-g-"]` 里的 `-g-(\d+)\.html`
- 翻页：页面底部橙色「查看更多」（外层 div 宽约 1191px）。
  **DOM `.click()` 无效，必须真实鼠标点击**；每次 +20 条；点前先 `scrollIntoView`。
- 主图原图：去掉 `?imageView2/...` 参数即原图（实测 800×800 / 1000×1000 JPEG）。
- **登录墙**：连续搜索 7~10 次后（2026-11-08 12:41 起）跳转
  `https://www.temu.com/login.html?from=...search_result...&login_scene=2`，
  之后搜索全部被拦。需人工在 ego 浏览器登录消费者站后继续。
  列表卡片不显示类目，脚本暂时把采集主题（定制餐巾）写入 category，搜索词留在 keyword。

## 卖家中心「机会商品」（/newon/invite-bids/list）

- 页面：商品管理 → 机会商品（全球），池子 9 万+，名称搜索 `餐巾` 命中 511 条。
- 列表接口：
  - `POST /api/kiana/ace/biddingInvitationSupplierRpcService/pageQueryBiddingInvitationOrderList`
  - `POST /api/kiana/mms/ace/biddingInvitationSupplierRpcService/queryBiddingTabCount`
- 请求带 `Anti-Content`（反爬签名）与 `mallid` 头，**直接调 403**。可行做法：
  1. `page.cdp("Network.enable")` + `page.events()` 清空事件
  2. 页面里设置「机会商品名称」输入框（React setter + input 事件）→ DOM 点「查询」
  3. 从 `Network.requestWillBeSent` 取 URL/头，`Network.getRequestPostData` 取原始 payload
  4. 用 `page.fetch(API, {headers: {content-type, mallid, Anti-Content}, body})` 重放；
     **同一签名头可改 pageNo/pageSize 连续翻页**（实测 pageSize=100、pageNo 2/6 均 200）
  5. 若 403：重新驱动一次页面查询刷新签名，再继续
- 响应字段（`result.list[].biddingInvitationOrder`）：
  `name`（标题）/ `catNameList`（完整类目路径数组）/ `catIdList` /
  `imageUrlList`（多图，首图=主图）/ `requirement`
- 主图：`pfs.logisticsmngmt.com/select-bidding-images/...` 签名 URL，`q-sign-time` 有效
  窗口约 **10 分钟**；取回响应后必须立刻下载。curl + 浏览器 UA + Referer 可用；
  ego 的 Node 原生 `fetch` 会失败，`page.fetch(..., {saveAs})` 也因 CORS 失败。
  并发 4 + 三次重试稳定（首轮 511 条缺 36 张，重试后 511/511 全有图）。

## 类目级联选择器（爆款跟卖/机会商品通用）

- 打开方式：对 `.IPT_inputWrapper` 派发 mousedown/mouseup/click（真实坐标点击也可）。
- 结构：列 `.CSD_menuItem_5-124-3`，滚动容器 `.CSD_menuUl_5-124-3`；
  父项点击展开右列（面板靠右时会向左展开），叶子项带 radio
  `label[data-testid=beast-core-radio]`，点 radio 选中并关闭。
- 面板靠右时列坐标会左移（实测 1240 → 958/1119），**不要写死坐标**，每次取 rect。
- 路径：家居、厨房用品 > 活动和派对用品 > 派对餐具 > 派对餐巾
  （注意标签是「活动和派对用品」，不是「活动与派对用品」）。
- 爆款跟卖（/newon/glo-bsr-flow）的「平台稀缺爆品」池里，按 活动和派对用品 过滤 = 0 条；
  名称搜 `napkin` 20 条、`餐巾` 34 条——该池子不适合定制餐巾采集。

## 登录后的消费者站变化（2026-11-08 下午实测）

- **直航 search_result.html 会渲染空白**（结果区不加载，页面只剩页脚），即使已登录；
  从首页搜索框输入关键词 + Enter 正常。脚本已改为「首页搜索框检索，URL 直航作回退」。
- 列表 DOM 改版：不再有 `img.goods-img-external`；稳定锚点是标题节点
  `[data-tooltip^="goodName-"]`（ID 在 `data-tooltip` 里，全标题在
  `data-tooltip-title`），主图取卡片内 src 含 `img.kwcdn.com/product` 的最大图。
  `.earth-wxt-collect-warp` 卡片容器仍在。兼容旧版选择器已写入 temu-search.mjs。
- 登录后「查看更多」可连续加载，每轮 +20；中文搜索可用（站点落地 Temu 英国站，
  界面简体中文）。
